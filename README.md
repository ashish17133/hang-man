Getting Started

Prerequisites

Install Python 3 on your computer.

Check your installation by running:

python --version

Installation

Clone this repository:

git clone https://github.com/YOUR_USERNAME/python-hangman.git

Navigate to the project directory:

cd python-hangman

Run the game:

python main.py

If your Python installation uses python3 instead, run python3 main.py.

🎯 How to Play

Start the game.

The computer selects a secret word at random.

Guess one letter at a time.

Correct guesses reveal the matching letters.

Incorrect guesses reduce your remaining attempts.

Guess the complete word before running out of attempts to win!
